# IIDS site (public)

Public static build of the Institute for Interdisciplinary Data Sciences (IIDS) website, University of Idaho. Served via GitHub Pages.

This repository contains only the generated public site. It is built from a private source repository by a build script and should not be hand-edited; changes are made in the source and rebuilt here.

- Entry point: `index.html` redirects to `mockups/landing_placeholder.html`.
- Static only. No backend, no build step required to serve.
